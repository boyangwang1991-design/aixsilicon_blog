# 输入怎样进入模型：从提问到向量

![Gemma 4 多模态输入与逐 token 生成的概念封面](../assets/generated/cover-zh.png)

[11 篇版索引](README.md) · 第 01 篇

用户只输入一句“为什么天空是蓝色的？”，E4B 的 Decoder 却不会直接读取这十个左右的汉字。它读取的是一串有消息边界的整数 ID，随后是每个 ID 对应的向量。如果再附上图片或音频，输入中还会出现由专用编码器产生的连续向量。先把这些不同的“长度”分开，后面讨论计算量、KV Cache 和端侧存储才有准确起点。

本系列以 Gemma 4 E4B 为例。它的语言主宽度为 2560，主干有 42 层；E4B 可以接收文字、图像和音频，最后生成文本。不同输入在前端各走各的路，进入语言主干时才排成一条有顺序的向量序列。

![文字、图片和音频如何汇入语言序列](../assets/generated/multimodal-overview-zh.png)

*图 1：文字先变成 ID 再查 Embedding；图片和音频经各自前端形成软 token。图是路径示意，方块数量不代表实际输入长度。*

## 一句提问，为什么不止一句话那么长

先只看文字。Tokenizer 把字符串切成词表里的片段，并为每段给出一个 ID。对固定 revision 的 `google/gemma-4-E4B-it`，关闭特殊 token 后，“为什么天空是蓝色的？”被编码成六段：`为什么｜天空｜是｜蓝｜色的｜？`。对应 ID 为 `38157, 141370, 237026, 240123, 40074, 237536`。切分边界由词表和编码规则决定，不等于人按汉语词义划出的词。

![固定 E4B Tokenizer 对这句提问的实际切分](../assets/generated/token-split-zh.png)

*图 2：六段及 ID 来自固定版 Tokenizer 的实际输出；全角问号也是一个片段。ID 是行号，不表示语义距离。*

聊天请求还要告诉模型谁在说话，以及下一轮该由谁回答。给这句话套上一条 `user` 消息并设置 `add_generation_prompt=True`，固定版聊天模板把六个内容 ID 扩成 **15 个位置**：前面四个位置建立消息起点和用户角色，后面五个位置结束用户轮次并打开 `model` 轮次。角色名和换行同样占位置。因此，Prefill 面对的不是屏幕可见的六段正文，而是完整模板编码后的序列；多轮历史和媒体占位槽还会继续改变长度。

![一条用户消息如何变成 15 个输入位置](../assets/generated/chat-template-zh.png)

*图 3：仅对应这一条用户消息及固定模板选项。不能把额外九个位置当作任意对话都不变的常数。*

## ID 怎样成为 Decoder 能计算的数

整数 ID 本身不携带可供矩阵乘处理的特征。主 Embedding 表 `E` 的逻辑形状是 `[262144,2560]`：词表中的每个 ID 指向一行训练得到的 2560 维参数。若输入是上述 15 个位置，查表后的主状态形状就是 `[1,15,2560]`。输入只取所需的 15 行，并不会在这一步把整张表做一次稠密矩阵乘。

这张主表在输出端还有第二种用途。走完 Decoder 后，末尾位置的隐藏向量要与词表候选比较，形成下一枚 token 的分数。输入端是按 ID **取行**，输出端是对候选 **打分**；共用参数不意味着两端访存方式相同。模型选出一个 ID、把它接回输入，才可能继续决定下一枚。推理期间权重保持固定，不会因为这一句提问自动改写。

![同一张主 Embedding 表的输入查行与输出打分](../assets/generated/embedding-shared-table-zh.png)

*图 4：两条路径共用主表，访问模式不同。图中高亮行仅用于示意，不对应上文真实 ID 地址。*

图片和声音不能先用文字 Tokenizer“切词”。它们经预处理和专门的编码器成为连续向量，再投影到语言主宽度，填入输入序列的预留位置。这些位置常称**软 token**：它们占据语言序列长度，却不是从普通文字词表查出的 ID。视频则先组织帧和时间信息，再走视觉路径。把文字 ID 数、媒体前端的 patch 或 Mel 帧数、最终软 token 数混为一谈，会同时误判前端工作量与语言 Prefill 长度。

进入主干之后，模型根据已有内容预测下一枚 token；已给定的前缀可以一起处理，尚未产生的回答要逐步接续。这解释了为什么同一个模型既有首 token 前的 Prefill，也有后续逐 token 的 Decode。下一篇从这里形成的 `[B,S,2560]` 状态出发，看一层 Decoder 怎样更新它。
