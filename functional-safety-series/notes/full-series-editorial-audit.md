# 30 章主线复核记录

2026-09-30。内部编辑记录，不作为公开正文引用。

## 本轮复核与补充

- 01–04：故障、错误、失效、危险与 ASIL 的层级已建立；02 补充安全状态、复位期间输出和整条响应时间链。真实 item 的 HARA 与安全目标仍需来自具体系统。
- 05–11：ECC、物理位交织、地址耦合固定码字、SRAM Controller、lockstep、watchdog、时钟/电源监控和 LBIST 均有机制与边界；08 增加“比较器报警前错误写已生效”的反例，09 增加定时中断仍喂狗而关键计算停滞的场景。
- 12–16：互连、E2E、访问隔离、错误中断和 Error Manager 的交接路径齐备；12 增加协议合法但地址送错的事务，14 增加 DMA 非法写与策略切换实验，15 增加检出至受控动作的时序与中断屏蔽反例，16 补充管理器自身故障的观察问题。
- 17–21：故障注入、Safety VIP、SPF/RF/MPF 分类、SPFM/LFM、FMEDA/PMHF 与 RTM 已衔接；18 补充“注入未激活不能算检出”的具体检查，21 增加从系统要求到 HSI、RTL、验证与交接的教学追踪表。
- 22–24：安全岛、NVM、ADC 的共享资源、数据身份和物理测量边界已覆盖。其诊断有效性必须在目标宏、模拟链和集成环境中评价。
- 25–30：TSC/LRS、DFMEA/FTA/DFA/FMEDA、Safety Manual、Safety Case/评估与 Mini Safety SoC 形成全流程；29 补启动、运行和降级模式下的响应差异，30 用独立需求与变异测试说明怎样发现 AI 与 checker 的共同遗漏。

## 发布前仍需取得的证据

1. 至少一条允许公开的真实 IP 故障链：配置、故障模型、注入位置、实际激活、观测波形或日志、响应时间及失败/修复记录。现有教学案例不得改写为实测结果。
2. 对涉及定量结论的章节，取得目标设计的失效率来源、模式分配、工作条件、诊断覆盖证据和统计口径；教学 `FIT` 算例不代表产品结论。
3. 对具体 SoC 或 IP 的安全能力主张，核对真实 HSR/HSI、RTL 配置、测试基线、集成假设与 Safety Manual 条款；证书或评估结论只在实际取得并核对范围后描述。
4. 依当前用户要求，图片仍为中文提示词占位；封面、正文图与英文全文尚未制作。正式发布前按仓库规范逐章完成双语、配图及版面核查。
